# Resume presentation

No personal resume or application material is included in this starter.

During the first `/prepare`, use an existing user resume as a factual source only after onboarding has classified its claims. The user may select it as a visual reference separately. Record the approved layout choice in `templates/prepare/DECISIONS.md`.

Deliver both editable DOCX and PDF when document tools are available. Render and inspect every page. Check typography, spacing, alignment, page breaks, dates, contact details and document metadata. The profile controls content; a visual reference never supplies or upgrades a claim.
