# Application package contents

Create under `applications/<company-role>/`:

- `README.md`: role, link, scores, status and file index
- `resume.md`: editable content source
- `Candidate_Resume_<Company>.docx` and `.pdf`
- optional `cover-letter.md`, `.docx` and `.pdf`
- `requirements-and-bullets.md`: evidence mapping and wording limits
- `gap-response-plan.md`: honest handling of gaps
- `application-answers.md`: observed fields, supported answers and user-controlled decisions
- `review-checks.md`: factual, visual and submission-safety checks
- `source/`: preserved posting and application-field evidence
- `apply-manifest.json`: exact reviewed documents and hashes when ready for `/apply`

Status remains PREPARED or READY for human review. Nothing is submitted.
