# `/prepare` workflow

Require completed onboarding and a unique selected job. Load the authoritative profile, accomplishments, preferences, scoring, saved job record, full live posting, and any existing package.

1. Preserve the posting and observed application fields in the package source folder.
2. Map every material requirement to confirmed or carefully bounded resume-supported evidence. Record missing evidence separately from missing experience.
3. Classify each gap as trivial, transferable, learnable, substantive, or disqualifying. Add an honest response plan; mitigation never becomes past experience or raises a score by itself.
4. Tailor headline, summary, skills, tools and bullets without changing factual meaning. Maintain coherent career breadth and chronology. Do not invent metrics, causal claims, tools, tenure or scope.
5. Create a resume in editable and PDF formats. Use the user's approved visual template if one exists; otherwise propose a clean format during the first preparation. Layout references provide appearance only.
6. Create a cover letter only when required, requested or useful. Explain the decision.
7. Draft supported application answers. Separate observed questions from likely interview themes. Leave salary, authorization, availability, demographics, legal attestations and missing facts to the user.
8. Render and inspect every delivered page for clipping, bad page breaks, unreadable text and inconsistent formatting.
9. Deliver the package for review. Do not upload, submit, message anyone or mark the job APPLIED.
